OBJETIVO
────────
Núcleo da interface gráfica da hein IDE.
Contém a janela principal (MainWindow) e todos os widgets de primeiro nível:
abas de código, abas de terminal, barra de título customizada, barra de busca
unificada e navegação Ctrl+Tab por ordem de uso (MRU).
É o ponto de montagem de todos os outros módulos da IDE.


RESPONSABILIDADES
─────────────────
• Instanciar e conectar todos os painéis (esquerdo, central, direito, terminais)
• Gerenciar o layout de três colunas com QSplitter (persistido em layout.json)
• Abrir/fechar projetos e arquivos; gerenciar abas de código
• Delegar execução de código ao TerminalTabWidget (Run_Out)
• Oferecer menu completo da IDE (Arquivo, Editar, Executar, Visualizar, Projeto, Ajuda)
• Coordenar a busca global: BarraCentral → MotorBusca → PainelResultados
• Sincronizar FileTree ↔ abas abertas (clique simples troca aba; duplo abre)
• Revelar automaticamente no FileTree o arquivo da aba ativa
• Gerenciar temas e configurações com hot-reload
• Gerenciar auto-save e persistência de sessão via GerenciadorAbas_AutoSalve
• Restaurar abas da sessão anterior na inicialização (lazy rehighlight 80ms/aba)
• Exibir chip de versão e notificar atualizações disponíveis
• Injetar saída do terminal ativo no contexto da IA
• Garantir instância única da IDE via QLockFile (main.py)

Criação de novo projeto:
    Abertura do Outdoor:
    MainWindow.abrir_outdoor()  ← chamado via QTimer na inicialização e via menu
        → se aba Outdoor já existe: mostra boas-vindas + ativa a aba
        → senão: instancia Outdoor, conecta sinais, abre aba com ícone mdi6.folder-star
    Outdoor._boas_vindas (PainelBoasVindas):
        → lista projetos recentes de recentes.json (apenas os que ainda existem no disco)
        → botões Novo Projeto / Abrir Projeto / Abrir Arquivo → emitem sinais → MainWindow
    Criação de novo projeto:
    MainWindow.novo_projeto()
        → se aba Outdoor já existe: Outdoor.mostrar_novo_projeto() + ativa aba
        → senão: cria Outdoor via _criar_outdoor(), depois mostrar_novo_projeto()
        → nunca abre segunda aba Outdoor


  PainelNovoProjeto (dialogo_novo_projeto.py):
    → _BuscadorPython(QThread) varre PATH + Python Launcher + locais comuns
         → emite encontrado(exe, versao) → popula lista de interpretadores
         → emite concluido() → atualiza label de status
    → botão "Navegar..." (destino): _ao_navegar_destino() abre QFileDialog na
         última pasta salva em QSettings("hein","hein_IDE")["ultima_pasta_destino"]
         (fallback PASTA_PROJETOS); ao escolher, salva a nova pasta em QSettings
    → usuário preenche nome, destino, seleciona Python (lista ou caminho manual)
    → botão "Criar Projeto" → _ao_criar():
         → valida campos
         → os.makedirs + cria .gitignore e main.py
         → exibe área de progresso interna (QLabel + QProgressBar)
         → inicia _CriadorVenv(caminho, python_exe)
              → usa python_exe explícito — nunca sys.executable (bug no .exe PyInstaller)
              → STARTUPINFO + CREATE_NO_WINDOW no Windows
              → sinal concluido(caminho) → _ao_venv_criado() → emite projeto_pronto
              → sinal erro(msg) → _ao_venv_erro() → emite projeto_pronto mesmo assim
                (falha silenciosa — projeto abre sem .venv)

  MainWindow._ao_projeto_criado(caminho, main_py):
    → fecha a aba do PainelNovoProjeto
    → set_projeto em todos os painéis
    → inicia Indexador
    → tabs.clear() + add_new_tab(main_py)
    → registra projeto nos recentes
    → atualiza status bar

Busca global:
  BarraCentral.buscar_global(termo)
    → MainWindow._ao_buscar_global(termo)
         • prefixo "@" → GrepThread no projeto
         • prefixo "#marcação" → limpar() → abrir_aba_busca_global() → AnotacoesThread
         • prefixo "#" (outro) → PainelOutline._alternar_modo("TAREFAS")
         • prefixo ">" → command palette
         • texto livre → busca no arquivo + GrepThread paralelo
         → MotorBusca.buscar(...)
         → PainelResultados.mostrar() / .adicionar()
    → item_clicado → _ao_selecionar_resultado_busca()
         → abre arquivo + vai para linha (com QTimer 450ms se arquivo novo)

Drag de aba — reorder:
  AbaWidget.mouseMoveEvent (threshold atingido, dentro da BarraTitulo)
    → _reordenando = True + grabMouse()
    → a cada movimento: BarraTitulo._atualizar_indicador_reorder()
         → _calcular_drop() → _IndicadorReorder.mover_para()
  AbaWidget.mouseReleaseEvent
    → releaseMouse() + BarraTitulo._finalizar_reorder()
         → TabWidget.mover_aba(de, para_antes_de)
              → tabBar().moveTab(de, destino) + _reindexar()
         → _reconstruir_abas()

Drag de aba — tear-off / split:
  AbaWidget.mouseMoveEvent (threshold atingido, fora da BarraTitulo ou abaixo)
    → _iniciar_tear_off() → TabWidget._pedir_split()
         → ZonaDropSplit.show_over() + grabMouse()
         → zona 'float': split_solicitado(editor, 'float')
              → _ao_split_solicitado() → destacar_aba() → JanelaEditorFlutuante
         → zona 'right': split_solicitado(editor, 'right') → _criar_painel_split()

REGRAS
──────
• Janela usa Qt.FramelessWindowHint — toda a barra de título é customizada (BarraTitulo)
• Splitters salvam largura em layout.json ao serem movidos (QTimer 500ms debounce)
• Larguras são restauradas 80ms após o __init__ (QTimer.singleShot(80))
• Clique simples no FileTree só troca para aba já aberta — NUNCA abre arquivo novo
• Duplo clique no FileTree abre o arquivo (sinal arquivo_selecionado)
• add_new_tab() normaliza caminhos com normcase + abspath antes de comparar
  — evita duplicata por barras mistas (/ vs \) ou capitalização diferente no Windows
• closeEvent() sempre chama salvar_sessao() antes de fechar a MainWindow
• restaurar_sessao() abre arquivos com delay escalonado (80ms/aba) — sem freeze;
  arquivo ativo (delay=0) abre imediatamente; os demais abrem em background
• sessao.json inclui 'projeto' (current_project_path); na restauração
  _configurar_projeto() é chamado ANTES das abas abrirem — tabs.project_path
  garante que add_new_tab() auto-aplica set_projeto() em cada editor
• _configurar_projeto() NUNCA chama tabs.clear() nem add_new_tab() —
  apenas configura painéis; abas são responsabilidade do lazy loader
• Temas JSON ficam em <RAIZ_IDE>/temas/*.json — cada arquivo = um tema;
  seleção persiste em layout.json como 'tema_json'; pré-carregado no startup
  antes de aplicar_na_janela() → janela já abre com o tema certo
• Quando a aba ativa muda, o FileTree revela e seleciona o arquivo correspondente
• Todo processamento pesado em QThread — NUNCA na thread principal
• Nunca hardcodar strings de fonte ou cor nos módulos — ficam em _CONFIGURA_/__init__.py
• Todos os logs via _LOG_/log.py — NUNCA print()
• Arquivo aberto que já existe como aba: apenas ativa, não duplica
• Criação de .venv SEMPRE em _CriadorVenv(QThread) — nunca subprocess.run() direto
• _CriadorVenv SEMPRE recebe python_exe explícito — nunca usa sys.executable
  (dentro do .exe PyInstaller, sys.executable aponta para o bundle, não para Python real)
• Toda lógica de criação de projeto (pastas, arquivos, venv, progresso) fica em
  dialogo_novo_projeto.py — a MainWindow apenas orquestra painéis após o projeto pronto
• Outdoor não pode ser aberto em duplicata — MainWindow usa _obter_outdoor()
• Aba 'Depurador' não pode ser aberta em duplicata — abrir_aba_debug() reutiliza
• fechar_aba() DEVE chamar _parar_sessao_atual() antes de removeTab() para
  PainelDebug — sem isso a QThread ClienteDAP fica viva indefinidamente
• ClienteDAP NUNCA deve ser destruído enquanto sua thread ainda roda:
  usar QThread.finished + deleteLater(), nunca assignment direto para None
• _ao_breakpoint_clicado() DEVE verificar se o arquivo do editor ativo
  corresponde ao arquivo da sessão de depuração antes de sincronizar BPs
  — descarta silenciosamente se arquivo diferente (guard de arquivo)
• _ao_trocar_aba_breakpoint() DEVE reconectar o sinal breakpoint_clicado
  ao NumeroLinhas da nova aba ativa para manter a sincronização correta
• Outdoor tem painéis internos via QStackedWidget: mostrar_boas_vindas() e
  mostrar_novo_projeto() alternam entre eles sem fechar a aba
• Ao trocar de projeto, _abrir_projeto_interno() DEVE chamar quit()+wait() no
  _indexador e _analisador_projeto antes de substituir a referência — sem isso
  o GC destrói o QThread enquanto ainda está rodando (exit code 1)
• _CampoBarraBusca._ajustar_altura() NUNCA deve usar documentSize() para medir
  linhas — o layout do documento é calculado com width=0 enquanto a barra nasce
  oculta e trava em MAX_LINHAS; usar texto.count('\n') + 1


OBSERVAÇÕES
───────────
• BarraTitulo esconde o tabBar() nativo do TabWidget e usa AbaWidget customizado
  para ter abas com cantos arredondados + ícones por extensão de arquivo
• NavegadorAbas usa installEventFilter na QApplication para capturar Ctrl+Tab global
• TerminalTabWidget tem aba "Log" permanente (sem botão de fechar) + abas de terminal
  e abas especiais (Pacotes, JSON Explorer)
• A barra de buscas tem dois modos independentes: modo global (prefixos @*:#>)
  e modo arquivo (Ctrl+F) — apenas o modo global aciona o MotorBusca
• Chip de versão na BarraTitulo fica desabilitado (cinza) até o atualizador
  confirmar que há uma versão nova — então vira clicável com link
• JsonExplorer é aberto como aba no TerminalTabWidget a partir da saída do Run_Out
• PainelResultados é filho do centralWidget() e posicionado sobre o TabWidget
  (flutua sobre o conteúdo, não empurra o layout)
• QLockFile usa tempfile.gettempdir() + "hein_ide.lock"; setStaleLockTime(0) garante
  que crash anterior não impeça o próximo start
• _CriadorVenv usa STARTUPINFO + CREATE_NO_WINDOW apenas em sys.platform == "win32"
  — sem efeito em Linux/macOS
• _BuscadorPython varre: PATH do sistema → Python Launcher (py --list-paths) →
  locais comuns Windows (%LOCALAPPDATA%\Programs\Python, C:\Python, etc.) →
  locais comuns Linux/macOS (/usr/bin, /usr/local/bin, ~/.local/bin, etc.)
• Se criação da .venv falhar, _ao_venv_erro() loga o erro, exibe aviso no painel
  e emite projeto_pronto mesmo assim — falha silenciosa conforme regra global
• PainelNovoProjeto foi projetado para receber expansões futuras: estruturas de
  projeto configuráveis, criação de banco de dados, scripts pré-montados
• AbaWidget.grabMouse() durante reorder — todos os eventos de mouse vão para a aba
  arrastada até releaseMouse(); permite rastrear posição mesmo fora da aba original
• _IndicadorReorder é filho de _container_abas mas NÃO está em nenhum layout —
  sobrevive ao _reconstruir_abas() que limpa apenas os layouts de linha
• tabBar().moveTab(from, to): se from < to, o destino efetivo é para_antes_de-1
  (a remoção desloca os índices); se from > to, o destino é para_antes_de diretamente
