IMPLEMENTADO  ✅
────────────────
• JanelaPicker leve para boot sem projeto e para diálogo de troca dentro do editor.
• No boot, o projeto escolhido é aberto pela MainWindow no mesmo processo do
  picker; o lançador separado fica reservado para abrir outra janela/projeto.
• Operações pesadas do picker são acionadas por ação explícita do usuário.
• Busca de interpretadores Python, criação de venv e clone Git usam workers separados.
• Criação de projeto gera a estrutura configurada, incluindo templates de arquivos e pastas.
• Encerramento da janela usa WA_DeleteOnClose, hide() imediato e closeEvent() para
  desconectar sinais e agendar destruição segura de threads Qt.
• Coluna central do GitHub exibe o estado da conta e oferece login opcional pelo
  Device Flow compartilhado do módulo Git.
• Contas salvas podem ser trocadas, adicionadas ou desconectadas sem apagar as
  demais contas; a lista de repositórios é reiniciada ao mudar de sessão.
• Clone iniciado pela tela de boas-vindas usa o serviço seguro compartilhado do
  Git, preservando a URL normal e removendo a credencial temporária ao terminar.

REGRAS CRÍTICAS DESTE MÓDULO
─────────────────────────────
• Não iniciar threads pesadas no __init__ de JanelaPicker; ações de rede, clone e
  descoberta de Python só podem começar após ação explícita do usuário.
• No boot, não relançar a IDE para abrir o primeiro projeto: emitir o caminho
  para main.py e trocar o picker pela MainWindow no mesmo processo.
• Dentro de uma IDE já aberta, abrir outro projeto em nova janela usa
  exclusivamente abrir_projeto_novo_processo().
• Ao trocar de projeto, ocultar o picker antes de iniciar o novo processo e preservar
  o fechamento seguro das threads no closeEvent().
