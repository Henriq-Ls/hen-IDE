# STATUS DO MÓDULO

## IMPLEMENTADO

### Núcleo Git
  - Autenticação OAuth Device Flow (git_autentica.py)
  - Persistência de token em %APPDATA%\hein\github_config.json
  - Login automático nas sessões seguintes
  - API GitHub REST v3 (git_api.py): obter usuário, listar repos,
    criar repositório, obter repositório e apagar repositório
  - Publicar projeto existente no GitHub (push inicial)
  - Clonar repositório remoto e abrir na IDE
  - Criar projeto novo com repositório no GitHub
  - Commit via git add + git commit (git_gerente.py)
  - Push para GitHub
  - Pull com recarga automática dos arquivos abertos
  - Histórico de commits (_JanelaHistorico)
  - Restauração de versão via git checkout <hash>
  - CHANGELOG.md criado junto com VERSION na publicação inicial (b__git_ui_conta)
  - registrar_changelog_commit() chamado após commit bem-sucedido em _ao_salvar()
    (painel Git bumpa VERSION antes do commit; utilitário só escreve CHANGELOG)
  - registrar_push() chamado após push bem-sucedido em _ao_enviar()
  - Ambas as chamadas via _UTILITARIOS_/versionamento.py (thread-safe, RLock)
  - Terminal de log interno colorido (git_terminal.py)
  - _DialogPublicar: nome, descrição e visibilidade antes de criar repo
  - Navegação entre 3 telas (git_ui.py)
  - _acao_criar_repo() — execução em background thread; botões
    bloqueados durante operação; falha trata None no callback
  - Sessão GitHub reutilizada pela tela de boas-vindas, sem Device Flow duplicado.
  - Clone, push, pull e remoto HTTPS preservam a URL normal; credencial temporária
    é criada apenas durante a operação e removida no final.
  - Respostas OAuth completas não são registradas no log.
  - Configuração global do Git não persiste credenciais automaticamente.

  - GerenciadorGit.limpar_cache_gitignore(pasta):
    Remove do índice Git arquivos rastreados que agora estão no .gitignore.
    Usa git ls-files -i --exclude-standard para encontrar os arquivos;
    executa git rm --cached -r -- <lista>. NÃO apaga arquivos do disco.
    Usuário deve fazer commit depois para registrar a remoção.
