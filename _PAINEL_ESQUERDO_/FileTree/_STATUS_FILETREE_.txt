IMPLEMENTADO  ✅
────────────────
• QTreeView + _IconProvider (QFileSystemModel) + _ProxyOrdem
• Ícones por extensão com suporte a packs (_PACK_ATIVO)
• Cache de ícones (_cache_icones) global ao módulo _auxiliares
• Ícones especiais: .venv → mdi.package-variant (#8BC34A),
                    .hein → mdi.folder-cog (#7E57C2)
• _ProxyOrdem: .venv no topo (rank 0), .hein segundo (rank 1),
  pastas antes de arquivos
• Indicadores Git por arquivo via _WorkerGit(QObject) em QThread
  (badge circular: + novo · ~ modificado · × deletado)
• Indicadores Git nas PASTAS — herdam o status mais crítico dos filhos:
  deletado(3) > modificado/renomeado(2) > novo(1)
  Implementado em _WorkerGit.rodar() após o loop de arquivos
• Texto colorido por status git via _DelegateGit (arquivos e pastas)
• Timer git de 5s automático enquanto projeto aberto
• "Adicionar ao Git" no menu → git add <arquivo>

• Modo staging integrado à FileTree:
    - entrar_modo_staging(): ativa checkboxes nos arquivos rastreáveis
    - sair_modo_staging(): volta ao visual normal
    - Ativação: sinal abrir_painel_git (botão "Main" do Git)
    - Desativação: ao trocar para aba Núcleo ou Exec.
    - Clique em arquivo rastreável togla o checkbox (não abre arquivo)
    - Pastas expandem/colapsam normalmente mesmo em staging
    - Checkbox desenhado com PE_IndicatorCheckBox nativo do Qt
    - Botões "✓ Marcar tudo" / "□ Desmarcar tudo" na barra_acoes
      (ocultos por padrão, visíveis apenas em modo staging)
    - arquivos_staging_selecionados() → lista de caminhos marcados
    - staging_checks: dict compartilhado por referência com _DelegateGit

• Menu de contexto completo via heinContextMenu:
    Executar (.py)
    ────────────────
    Novo Arquivo        (Shift+F1)
    Nova Pasta          (Shift+F2)
    ────────────────
    Copiar              (Ctrl+C)
    Colar               (Ctrl+V)  — desabilitado se clipboard vazio
    Duplicar            (Ctrl+D)  — desabilitado se nada selecionado
    ────────────────
    Copiar Caminho      → clipboard do sistema (caminho absoluto)
    ────────────────
    Renomear            (F2 / Shift+F3)
    Apagar              (Delete)
    Desfazer            (Ctrl+Z)  — desabilitado se histórico vazio
    ────────────────
    Mostrar no Explorador
    Abrir no Navegador (.html)
    Adicionar ao Git (se .git existir)
    ────────────────
    Enviar para IA
    Restaurar último apagado / Esvaziar Lixeira

• Menu da lixeira dedicado ao clicar em .hein/lixeira/
• Rename inline via _tree.edit() (sem popup) + _ao_renomear_inline
  conectado a model.fileRenamed → atualiza abas abertas
• Apagar → .hein/lixeira/ (nunca deleta permanentemente)
• Ctrl+Z (desfazer) → pilha _historico: delete / rename / colar / duplicar
• Restaurar item específico da lixeira via QFileDialog
• Esvaziar lixeira com confirmação
• Drag-and-drop InternalMove para mover arquivos/pastas

• Atalhos de teclado via eventFilter:
    F2          → renomear inline
    Shift+F1    → novo arquivo (pasta do item selecionado)
    Shift+F2    → nova pasta  (pasta do item selecionado)
    Shift+F3    → renomear inline (alias de F2)
    Delete      → apagar (move para lixeira)
    Ctrl+C      → copiar (clipboard interno)
    Ctrl+V      → colar
    Ctrl+Z      → desfazer
    Ctrl+D      → duplicar (gera nome_copia.ext na mesma pasta)

• Foco devolvido à árvore após clique simples em arquivo
  (QTimer.singleShot → _tree.setFocus) — garante que os atalhos
  continuem funcionando após o editor trocar de aba

• barra_acoes (QHBoxLayout separado) entre MenuRecenteProjeto e a
  árvore com botões: ajuda / expandir tudo / colapsar tudo /
  filtrar / Marcar tudo / Desmarcar tudo (últimos dois ocultos fora do staging)

• Indentação da árvore: 12px (era 22)
• QShortcuts Ctrl+Alt+± removidos (conflitavam com o editor)
• Sinais: arquivo_selecionado, arquivo_clicado_simples,
          arquivo_enviado_para_ia, executar_arquivo
• Clique simples → arquivo_clicado_simples (nunca abre duplicata)
• Clique simples em pasta → toggle expand/colapso
• revelar_arquivo(): expande todos os pais + scrollTo + select
• _filtrar_arvore(): expandAll + nameFilters; colapsa ao limpar
• set_projeto(): mostra nome truncado + tamanho total em MB
• _atualizar_tamanho_venv(): exibe tamanho da .venv no display
• trocar_pack_icones(): recria model/proxy/delegate do zero
  (delegate recriado com staging_checks e modo_staging preservados)
• Tema com gradiente 3 pontos (ini/meio/fim) via paintEvent
• Hot-reload de tema via atualizar_tema()
• Pacote dividido em 5 módulos:
    __init__.py / _auxiliares.py / _workers.py / _modelo.py / painel.py
