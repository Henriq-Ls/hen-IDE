# STATUS DO MÓDULO

## IMPLEMENTADO

  - ExecutavelExplorer ligado à aba Executável do painel inferior
    · Painel grava nome/versão/ícone/arquivo inicial dentro do projeto ativo
    · Build local usa a .venv do projeto e módulos _EXECUTAVEL_ compatíveis
    · Release gera workflow e build_ci.py autônomo dentro do projeto
    · Push usa a sessão segura do Git; sem token em URL/argumentos e sem force-push
    · Tag já existente no GitHub é recusada em vez de sobrescrita

  ── Explorers de configuração ────────────────────────────────────

  - _TERMINAIS_/thema_explorer.py  [NOVO — Sessão 10]
    ThemaExplorer(QWidget) — painel visual para thema.json.
    · Swatch colorido _Swatch(QLabel) clicável → QColorDialog com alpha
    · Valores "transparent" exibem swatch xadrez + campo de texto livre
    · Organizado em 12 seções: meta, interface, editor, terminal,
      terminal_run, painel_arquivos, painel_outline, painel_git, painel_ia,
      log, grafo, menu_lateral, menu_contexto
    · Sub-seções "sintaxe" (24 cores) e "cores_ansi" (16 cores) indentadas
    · Salvar: json.dump → thema.json → hot-reload via gerenciador_tema
    · QFileSystemWatcher bidirecional: mudança externa → recarrega UI
    · _recarregar_se_necessario() via mtime antes de reconstruir

  - _TERMINAIS_/configurar_explorer.py
    ConfigurarExplorer — painel visual para configurar.json (Ctrl+5).
    Seções completas: ui (borda, abas, fonte, aba_estilo), editor (cursor,
    fonte), terminal, outline, painel_arquivos, painel_ia, git, gutter
    (7 SpinBoxes), perfil (6 QLineEdit). Layout 2-col QGridLayout.
    Controles: ComboBox de fonte, SpinBox pt/inteiros, QCheckBox, QLineEdit.

  - _TERMINAIS_/atalho_explorer.py
    AtalhoExplorer — painel visual para atalhos.json (Ctrl+4).
    Grupos coloridos por contexto. Coluna tecla (editável) + ação (read-only).
    Hot-reload registra novos QShortcuts em tempo real.

  - _TERMINAIS_/autocomplete_explorer.py
    AutocompleteExplorer — painel visual para autocomplete.json (Ctrl+6).
    Seção ambiente (pasta_venv, site_packages) + snippets (add/remove).

  - _TERMINAIS_/nucleo_explorer.py
    NucleoExplorer — painel visual para nucleo.json (Ctrl+7).
    7 seções: formatador, diagnóstico, índice, ambiente, ia,
    documentador (QPlainTextEdit), exportar (checkboxes).

  - _TERMINAIS_/prompt_nucleo_explorer.py  [NOVO — Sessão 28 / IMP-D]
    PromptNucleoExplorer(QWidget) — editor visual para nucleo_prompts.json (Ctrl+0).
    2 seções:
      Docstrings    — prompts para gerar docstring de função (3 lin) e classe (3 lin)
      Documentador  — prompts para doc_pasta (6 lin), resumo_projeto (4 lin),
                      readme_github (8 lin), doc_site (8 lin)
    Botão "Salvar Alterações": grava nucleo_prompts.json + invalida cache nucleo_ia.
    Botão "Restaurar Padrão": confirma + regrava padrão hardcoded + recarga.
    Aberto diretamente por Ctrl+0 (não via abrir JSON no editor).
    QFileSystemWatcher: hot-reload bidirecional — se o JSON mudar no disco,
    o Explorer recarrega automaticamente (debounce 700ms, igual ao NucleoExplorer).

  SINCRONIZAÇÃO BIDIRECIONAL (todos os 6 Explorers):
  - QFileSystemWatcher por explorer monitora seu JSON
  - _recarregar_se_necessario() compara mtime antes de reconstruir UI
  - _ultimo_mtime rastreado para evitar recargas desnecessárias

  ── Depurador Integrado (Sessões 9 + 11) ─────────────────────────

  - Botão 🐛 emite debug_solicitado = Signal()
  - ClienteDAP(QThread): protocolo DAP completo sobre TCP
    · initialize → aguarda response → attach → aguarda initialized event
      → setBreakpoints → configurationDone  (ordem correta; Sessão 11)
    · Sem BPs: subprocess recebe --stop-on-entry na linha de comando
      (stopOnEntry no corpo do attach é ignorado pelo debugpy em --listen)
    · set_breakpoints(linhas) público — chamável da thread principal
    · Loop de eventos: stopped / continued / exited / terminated
    · stackTrace → scopes → variables a cada pausa
    · Filtro de variáveis internas (__xxx, @py_xxx)
    · Porta TCP dinâmica, thread-safety via Lock, CREATE_NO_WINDOW
    · _encerrar(): terminate/kill ANTES de drenar stderr (sem deadlock)
  - PainelDebug(QWidget): controles Continuar/Próxima/Entrar/Sair/Parar
    · iniciar_sessao(arquivo, python_path, breakpoints=[])
    · sincronizar_breakpoints(breakpoints) — envia BPs via set_breakpoints()
    · Estados visuais: Aguardando / ⏸ Pausado / ▶ Executando / ■ Parado / ✕ Erro
    · QTreeWidget de variáveis: Nome / Tipo / Valor
    · _ao_thread_finalizada(): conectado a QThread.finished — destrói
      o ClienteDAP via deleteLater() após o thread do SO terminar;
      elimina 'QThread: Destroyed while thread is still running'
    · _parar_sessao_atual(): desconecta finished, parar() + wait(8s) +
      deleteLater() — cleanup sem race condition nem dupla execução
  - fechar_aba() em terminal_tab_widget.py chama _parar_sessao_atual()
    antes de removeTab() quando o widget for PainelDebug
  - terminal_tab_widget.painel_debug_ativo() — retorna PainelDebug ativo
    ou None (usado por main_window para sincronizar BPs)
  - main_window._ao_breakpoint_clicado(linha): sincroniza BPs com sessão
    ativa somente se o arquivo do editor == arquivo da sessão (guard)
  - main_window._ao_trocar_aba_breakpoint(): reconecta sinal de BP ao
    NumeroLinhas da aba que acabou de ficar ativa

  ── add_new_tab_com_conteudo (tab_widget.py) ─────────────────────
  - Cria aba no editor com conteúdo já preenchido (código gerado pelo JsonExplorer)

  ── Mult_Terminais/ — execução linguagens não-Python ────────────────

  - ExecutorTerminal(QWidget): executa arquivos de linguagens com can_run=True
    · Estado sem_ferramenta: label de aviso + botão "Como instalar"
    · Estado pronto: campo de comando editável + ▶ Run + ■ Stop
    · QProcess não-bloqueante: stdout/stderr capturados em tempo real
    · Aba reutilizada por nome de linguagem (sem duplicatas)

  - ExecutorExplorer(QWidget): painel visual para executores.json (Ctrl+8)
    · _LinhaExecutor: nome + status ✓/✗ + campo + botões Salvar/Verificar
    · _verificar_tudo() via shutil.which em todas as linguagens
    · _recarregar_se_necessario(): padrão dos outros Explorers

  - executores.json: JavaScript, TypeScript, Shell, Lua, Makefile configurados

  - F1 silencioso implementado:
    · can_run=True  → abrir_executor_terminal(nome, arquivo)
    · can_run=False → return (sem ação, sem erro)

  - Imports diretos em terminal_tab_widget.py (×2) e main_window.py (×1):
    from _TERMINAIS_.Mult_Terminais.terminal_executor import ExecutorTerminal
    from _TERMINAIS_.Mult_Terminais.executor_explorer import ExecutorExplorer
