ARQUIVO 3 — _UTILITARIOS_/licenca.py  (NOVO — não existe ainda)
══════════════════════════════════════════════════════════════════════════════

  Todo o cérebro do sistema. Funções:

  ── _gerar_maquina_id() → str ────────────────────────────────────────────
    1. Tenta ler maquina_id.txt do AppData — se existe, retorna direto.
    2. No Windows: lê HKLM\SOFTWARE\Microsoft\Cryptography\MachineGuid (winreg)
       Fallback: str(uuid.getnode())
    3. Retorna hashlib.sha256(raw.encode()).hexdigest()[:16].upper()
    4. Salva em maquina_id.txt para reutilizar sempre.
    Dependências: winreg (stdlib Windows), hashlib, uuid (stdlib)

  ── _ler_cache() → dict | None ───────────────────────────────────────────
    Lê licenca_cache.json do AppData.
    Retorna None se ausente, vazio ou JSON corrompido.

  ── _salvar_cache(resposta: dict) → None ─────────────────────────────────
    Salva { ...resposta_api..., "timestamp": datetime.utcnow().isoformat() }
    em licenca_cache.json.

  ── _cache_valido(cache: dict) → bool ────────────────────────────────────
    TTL depende do campo "modo" gravado no cache:
      "gratuito"   → 30 dias
      "licenciado" → 72 horas
      qualquer outro → 72 horas
    Compara datetime.utcnow() com cache["timestamp"] + TTL.

  ── verificar_licenca(serial: str | None = None) → dict ──────────────────

    FLUXO COMPLETO (com brecha corrigida):

      1. Se VERIFICACAO_ONLINE is False
           → retorna {"valida": True, "modo": "gratuito"} IMEDIATAMENTE.
             (Fase 1: nem toca cache, nem faz rede. Zero impacto.)

      — A partir daqui só executa em Fase 2 (VERIFICACAO_ONLINE = True) —

      2. Lê cache local (_ler_cache()).

      3. Se cache existe E _cache_valido(cache) is True
           → retorna cache. (Hit de cache, sem rede.)

      4. Tenta POST /api/licenca/validar com timeout=LICENCA_TIMEOUT_SEGUNDOS.
           Body: { "serial": serial ou cache.get("serial"), "maquina_id": _gerar_maquina_id() }

      5. Se API responde com sucesso
           → _salvar_cache(resposta) → retorna resposta.

      6. Se timeout ou erro de rede E cache existe (mesmo vencido)
           → retorna cache. (Grace period: até 7 dias após expirar o TTL.)
             O chamador em main.py trata como válido neste caso.

      7. Se timeout ou erro de rede E SEM cache algum
           → retorna { "valida": False, "modo": "sem_licenca",
                        "mensagem": "Não foi possível verificar sua licença.\n"
                                    "Conecte à internet e tente novamente." }
             BLOQUEIA — não existe fallback gratuito em Fase 2.

    NOTA SOBRE A BRECHA (corrigida no passo 7):
      O passo 1 garante que em Fase 1 (VERIFICACAO_ONLINE=False) a função
      retorna antes de qualquer fallback. Assim o "libera sem cache" do
      passo 7 só é alcançado em Fase 2, onde bloquear é o comportamento
      correto. Desligar a internet na primeira abertura não adianta:
      sem cache e sem API → bloqueio com mensagem clara.

  Dependências: requests (já no projeto), hashlib, json, datetime,
                winreg (stdlib Windows), uuid (stdlib)
