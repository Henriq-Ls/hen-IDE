IMPLEMENTADO  ✅
────────────────
• log_print.py — LogPrint(QObject) Singleton: output voltado ao USUÁRIO
  Signals: nova_saida(str, str), status_msg(str), pedido_foco()
  Métodos: info/ok/aviso/erro(msg) — emite para painel Saída + status bar
  Separação clara com log.*: log.* → arquivo em disco; log_print.* → UI

• icones.py — icone_tema() wrapper qtawesome com hot-reload de tema
• atualizador.py — _WorkerVerifica(QThread), notifica barra_aba_topo de update
• hein_context_menu.py — heinContextMenu(QMenu) estilizado, thema.json
• hein_pou_pap.py — HeinPopup(QDialog): aviso/erro/info/confirmar/pacote
  Substitui QMessageBox em toda a IDE — design consistente com menu_contexto
• hein_venv_guard.py — exigir_pacote(): guarda acesso a libs da _venv_hein_
  via sys.path; popup automático se pacote não instalado
• hein_migrador_venv.py — _ThreadMigracao(QThread): migração de venv entre
  interpretadores (freeze → rmtree → criar → install); UI não trava
• hein_python_picker.py — hein_PythonPicker: seleção de Python do sistema
• hein_pacotes_util.py — persistência JSON de lista de pacotes
• gerenciador_pacotes.py — GerenciadorPacotes(QWidget) tematizado

• versionamento.py — utilitário thread-safe (threading.RLock de módulo)
  para gerenciar VERSION e CHANGELOG.md do projeto aberto.
  API pública:
    criar_changelog_inicial(caminho)        → publicação inicial
    registrar_changelog_commit(caminho, msg, versao) → pós-commit (painel Git)
    registrar_commit(caminho, msg)          → bump + CHANGELOG (IA / HEIN-GIT)
    registrar_push(caminho)                 → entrada de push no CHANGELOG
    checar_regressao_versao(caminho, versao)→ True se versão nova < atual
    registrar_release(caminho, versao, desc)→ sincroniza VERSION + CHANGELOG
  Chamado por: b__git_ui_conta, c__git_ui_projeto, ias_handlers, executavel_explorer

• processo_sem_console.py — função universal para iniciar subprocessos internos
  sem janela de console no Windows, combinando STARTUPINFO/SW_HIDE e
  CREATE_NO_WINDOW. Consumida pelos processos auxiliares de _APP_, _EDITOR_,
  _PAINEL_ESQUERDO_, _TERMINAIS_ e pelos utilitários que executam comandos.
