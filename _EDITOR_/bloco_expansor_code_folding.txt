## 1.1 Linhas em branco dentro do bloco nao sao ocultadas

ARQUIVO: _EDITOR_/Core/editor_dobramento.py

COMPORTAMENTO ESPERADO:
  Ao colapsar um bloco, os numeros de linha pulam direto do cabecalho para a
  primeira linha visivel apos o bloco — sem nenhum espaco entre elas.
  Exemplo: linha 32 → linha 83 → linha 84.

COMPORTAMENTO ATUAL (BUG):
  Linhas em branco dentro do bloco colapsado ficam visiveis, criando espaco
  em branco entre o cabecalho e o proximo bloco.

CAUSA RAIZ:
  editor_dobramento.py : recolher_bloco()
    if proximo.text().strip() == "":
        proximo = proximo.next()
        continue    — avanca sem chamar setVisible(False)

  Linhas em branco sao ignoradas pelo loop — ficam visiveis mesmo dentro do
  bloco colapsado.

CORRECAO APLICADA (IMP-01):
  Substituir o continue por lista pendentes[].
  Linhas em branco sao acumuladas. Quando a proxima linha real ainda esta
  dentro do bloco (indentacao maior), os pendentes sao ocultados junto.
  Quando a proxima linha real encerra o bloco, os pendentes ficam visiveis
  (pertencem ao escopo externo).

## 4.2 Ctrl++ com selecao abre apenas os primeiros blocos

ARQUIVO: _EDITOR_/Core/editor_acoes.py

COMPORTAMENTO ESPERADO:
  Com varios blocos fechados, selecionar todos os cabecalhos e pressionar
  Ctrl++ expande TODOS.

COMPORTAMENTO ATUAL (BUG):
  Apenas os primeiros blocos (topo da selecao) sao expandidos.

CAUSA RAIZ:
  O codigo usa reversed() para fechar E para abrir.
  reversed() (de baixo pra cima) e correto para FECHAR (filhos antes dos pais).
  Para ABRIR e incorreto — a ordem certa e de cima pra baixo (pais antes dos filhos).

CORRECAO APLICADA (IMP-03):
  Detectar a tecla:
    Key_Minus → fechar → reversed() (de baixo pra cima)
    Key_Plus  → abrir  → ordem normal (de cima pra baixo)

ARQUIVO: _EDITOR_/Core/editor_acoes.py

MAPA DE ATALHOS DEFINIDO:

  Atalho          Acao
  ──────────────  ─────────────────────────────────────────────────────────
  Ctrl+-          Toggle fold — bloco atual ou selecionados   (ja existia)
  Ctrl++          Toggle fold — bloco atual ou selecionados   (ja existia)
  Ctrl+Alt+-      recolher_tudo() — fecha TODOS os blocos     (NOVO)

        Key_Minus → recolher_tudo()
        Key_Plus  → expandir_tudo()
